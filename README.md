# AI-Assisted Development Environment Setup

## Project Overview

This repository was created as the first step of a portfolio-based hiring process.

The goal of this task was to set up a basic AI-assisted development environment, create a public GitHub repository, document the setup process, and push the work to GitHub.

This project is intentionally simple. The main focus is not on building an application yet, but on demonstrating that I can:

- Set up development tools.
- Follow technical instructions.
- Use GitHub for version control.
- Document my process clearly.
- Use AI tools responsibly to support learning and execution.

## Issues I Ran Into and How I Solved Them

### Issue 1: Deciding Whether to Use GitHub Desktop or Cursor for Git

I installed GitHub Desktop, but later I found that Cursor already had built-in Git and Source Control features.

At first, I was unsure whether I should push the repository through GitHub Desktop or Cursor.

**How I solved it:**

I decided to use Cursor directly because the repository was already open there, and it was more efficient to commit and push without switching tools.

This helped me understand that there are multiple ways to complete the same Git workflow.

---

### Issue 2: Understanding the GitHub Workflow

The task required me to create a repository, add a README file, commit the change, and push it to GitHub.

As a beginner workflow, I had to make sure I understood the difference between:

- Creating a file.
- Saving a file.
- Committing a change.
- Pushing the commit to GitHub.

**How I solved it:**

I followed the process step by step and used Cursor's Source Control interface to manage the commit and push.

I also used ChatGPT to help clarify the documentation and make sure I explained the process correctly.

### Issue 3: Writing the README Clearly

**How I solved it:**

I structured the README into clear sections:
